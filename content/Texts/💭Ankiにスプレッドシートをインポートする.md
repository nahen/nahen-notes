![[ファイルをインポート.png]]

Ankiのトップページから「ファイルをインポート」を選び、インポートするTSVファイルをファイルダイアログから選ぶ。

#### ファイル
![[インポート_ファイル.png]]

| 項目名            | 設定値                    |
| -------------- | ---------------------- |
| フィールドの区切り      | コンマ(CSVの場合)、タブ(TSVの場合) |
| フィールド内でHTMLを使う | ON                     |

#### インポートのオプション
![[インポート_オプション.png]]

| 項目名       | 設定値                                     |
| --------- | --------------------------------------- |
| ノートタイプ    | （[[💭読書用ノートタイプを新しく作る\|新しく作った読書ノートタイプ]]） |
| デッキ       | （[[💭読書用の親デッキと子デッキを作る\|新しく作った子デッキ]]）    |
| 既存のノート    | 更新                                      |
| 重複チェックの範囲 | ノートタイプ                                  |
#### フィールドの割り当て
![[インポート_フィールドの割り当て.png]]

ここで、スプレッドシートの1列目と2列目がデッキの表面・裏面に問題なく対応づけできていることを確認する。
