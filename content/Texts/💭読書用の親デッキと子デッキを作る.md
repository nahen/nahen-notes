読書用のデッキは、以下の2つのデッキに分かれる。
- 書籍やPDF、ブログ記事ひとつひとつに対応した「子デッキ」
- 子デッキ群をひとつにまとめる、入れ物としての「親デッキ」

![[読書デッキ構成.webp]]

各々の子デッキで生まれる新規カードと既存カードは、親の読書デッキの中に集まる。ユーザは親デッキだけを繰ればよい。

![[読書デッキ運用例.webp]]

## (1) 親デッキの設定
まずは読書用の親デッキを作る。親デッキのオプションを開いて、以下の3項目の設定を変更する。特に、[[#表示順序]]は必ずこの値にしたい。

- 一日の上限
- 表示順序
- 兄弟関係のカードの非表示

以降の表では、デフォルトから変更した箇所にハイライトを引いている。

### 一日の上限
![[デッキ_1日の上限.png]]

| オプション                  | 設定値     |
| ---------------------- | ------- |
| 一日の新規カード導入枚数の上限        | ==30==  |
| 一日の復習枚数の上限             | ==300== |
| 復習枚数の上限に関係なく新規カードを導入する | ON      |
| 上限をメインデッキから適用          | OFF     |

新規カード・復習カードの上限値は各々で好きな値を設定する。1日で無理なく消化できる量にするとよい。（私の場合、新規上限が30枚、復習上限が300枚）

Ankiユーザの中には「[新規も復習も上限9999！](https://leananki.com/best-settings/)」という猛者もいる。私も一度試したが、読書デッキには合わなかった。

### 表示順序
![[デッキ_表示順序.png]]

| オプション名                          | 設定値                 |
| ------------------------------- | ------------------- |
| 新規カードを集める順序                     | ==位置（新規カード番号）の昇順==  |
| 集めた新規カードを並べる順序                  | ==集めたときの順序==        |
| 新規カード表示のタイミング                   | 復習に混ぜ込む             |
| 日をまたいだステップの習得中（再習得中）カード表示のタイミング | 復習に混ぜ込む             |
| 復習カードを並べる順序                     | 期日超過日数が多い順→同日数はランダム |

新規カードの順序は、それぞれ「位置（新規カード番号）の昇順」「集めたときの順序」としている。 **一度目の読書は本と同じように、上から下へと順番に読みたいからだ。**

ちなみにお試しで、新規カードの順序を「ランダム（ノート単位）」に設定したことがある。こうすると、新規カードの出る順番がバラバラになる。これはこれで面白いが、テキスト全体の意図がつかみづらくなるので注意。

### 兄弟関係のカードの非表示
![[デッキ_兄弟関係のカード.png]]

| オプション名                                  | 設定値    |
| --------------------------------------- | ------ |
| 兄弟関係の新規カードを同じ日に表示しない                    | ==ON== |
| 兄弟関係の復習カードを同じ日に表示しない                    | ==ON== |
| 兄弟関係の習得中カードで、ステップが日をまたいでいる場合は、同じ日に表示しない | OFF    |

兄弟関係のカードとは、同じノートから作られた複数のカードを指す。私は新規・復習ともONにしている。同じ日に同じ文面を何度も読まされるのは好きではない。

## (2) 子デッキの設定
次に子デッキを作る。子デッキのオプションを開いて、親と同じく以下の3項目の設定を変更する。

- 一日の上限
- 表示順序
- 兄弟関係のカードの非表示

以降の表は、デフォルトから変更した箇所にハイライトを引いている。

##### 一日の上限
![[子デッキの一日の上限.png]]

| オプション                  | 設定値   |
| ---------------------- | ----- |
| 一日の新規カード導入枚数の上限        | ==3== |
| 一日の復習枚数の上限             | 200   |
| 復習枚数の上限に関係なく新規カードを導入する | ON    |
| 上限をメインデッキから適用          | OFF   |

新規カードの上限も個人の自由で決めるとよい。私の場合、[[📝インターリーブ]]を実施するために、新規カードの上限を3つに絞っている。

##### 表示順序
![[子デッキの表示順序.png]]

| オプション名                          | 設定値                 |
| ------------------------------- | ------------------- |
| 新規カードを集める順序                     | ==位置（新規カード番号）の昇順==  |
| 集めた新規カードを並べる順序                  | カードタイプ順             |
| 新規カード表示のタイミング                   | 復習に混ぜ込む             |
| 日をまたいだステップの習得中（再習得中）カード表示のタイミング | 復習に混ぜ込む             |
| 復習カードを並べる順序                     | 期日超過日数が多い順→同日数はランダム |

こちらも新規カードの順序は、「位置（新規カード番号）の昇順」としている。

##### 兄弟関係のカードの非表示
![[子デッキの兄弟カード.png]]

| オプション名                                  | 設定値    |
| --------------------------------------- | ------ |
| 兄弟関係の新規カードを同じ日に表示しない                    | ==ON== |
| 兄弟関係の復習カードを同じ日に表示しない                    | OFF    |
| 兄弟関係の習得中カードで、ステップが日をまたいでいる場合は、同じ日に表示しない | OFF    |

新規の兄弟カードは同じ日に表示しないように設定している。復習カードはどちらでもよい。
