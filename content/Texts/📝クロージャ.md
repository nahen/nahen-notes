title: 📝クロージャ（closure）
---
関数のうち、関数Aの内部で変数と関数A'を定義し、なおかつ関数A'を返すもの。関数のなかに変数と関数を内包したもの。こうすると、関数Aが実行を終了したあとでも、関数A内の変数を関数A'が参照し続ける。そのため、変数が破棄されずに残り続ける。

たとえば、カウンターの実装（この関数をこれまでに何回呼び出したかを数える）に使える。

## JavaScriptの例[^1]
```javascript
function makeFunc() {
  const name = "Mozilla";
  function displayName() {
    console.log(name);
  }
  return displayName;
}

const myFunc = makeFunc();
myFunc();
```

[^1]: このコードは[クロージャ - JavaScript \| MDN](https://developer.mozilla.org/ja/docs/Web/JavaScript/Guide/Closures)より抜粋。
