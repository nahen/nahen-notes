古代ギリシャの数学者・エラトステネスが考案したとされる[^1]、素数判定のアルゴリズム。ある上限内に存在する素数を、割り算を使わずに[^2]見つけ出せることが特徴。

- 2〜上限値 $n$ 内のすべての整数を素数だと仮定する
- 整数 $i (2 \leq i \leq n)$ が素数か否かを判定する
	-  $i$ が素数とみなされている場合、$i$ の倍数（$2i, 3i, \dots ji$ ）をすべて素数でないと置く
	-  $i$ が素数とみなされていない場合は、何もしない
- これを $n$ まで繰り返すと、$2〜n$ 内の素数のリストが手に入る

## Racketによるコード
1. 上限値 $n$ が長さとなるBoolean配列を用意する
	1. 要素はすべて`True`で初期化する
2. 0と1は素数ではないので、配列の0と1番目に`False`を入れる
3. 2〜$\sqrt{n}$ 内の整数 $i$ で、以下を繰り返す
	1. 配列の $i$ 番目の要素が`True`なら次の処理を行う
		1. 配列の $i^2, i^2+i, i^2+2i, \dots$ 番目の要素をすべて`False`に置き換える
	2. 配列の $i$ 番目の要素が`False`なら何もしない
4. 繰り返しが終わったら、素数だけが`True`となるBoolean配列（篩）のできあがり

```racket
(define (make-p-table limit)
  (define v (make-vector limit #t))
  (define (not-prime! n)
    (vector-set! v n #f))
  ; 0と1は素数ではないので除外
  (not-prime! 0)
  (not-prime! 1)

  (for ([i (in-range 2 (add1 (integer-sqrt limit)))]
        #:when (vector-ref v i))
    (for ([j (in-range (* i i) limit i)])
      (not-prime! j)))
  v)
```

## 時間計算量: $O(n*\log(\log n))$
各素数の倍数を消す作業のステップ数を考える。
- 2の倍数を消す：$\frac{n}{2}$
- 3の倍数を消す：$\frac{n}{3}$
- 5の倍数を消す：$\frac{n}{5}$
- …

これらのステップ数を足し合わせると、以下のようになる。右辺を見ると、素数の逆数の和をn倍したものになっている。
$$\frac{n}{2} + \frac{n}{3} + \frac{n}{5} + \frac{n}{7} + \dots = n( \frac{1}{2} + \frac{1}{3} + \frac{1}{5} + \frac{1}{7} + \dots )$$
[メルテンスの第二定理](https://ja.wikipedia.org/wiki/%E3%83%A1%E3%83%AB%E3%83%86%E3%83%B3%E3%82%B9%E3%81%AE%E5%AE%9A%E7%90%86)によると、素数の逆数の和は以下の値に近似できる。
$$ \sum_{p \leq n}\frac{1}{p} = O(\log(\log n))$$
これを右辺に代入すると、 $n * O(\log(\log n)) = O(n\log(\log n))$ が導き出せる。

[^1]: 篩について記したエラトステネスの著書は見つかっていないらしい。一番古いもので言及しているのは、2世紀の哲学者ニコマコスの著書『[算術入門](https://archive.org/details/NicomachusIntroToArithmetic/nicomachus_introduction_arithmetic.pdf)』。

[^2]: 素数判定をBoolean配列の読み取りではなく、試し割り法で実装した「[似非エラトステネスの篩](https://rion778.hatenablog.com/entry/2021/02/13/144138)」がある。この場合、本来よりも時間計算量が大きくなる。2021年頃に少し話題になったらしい。
