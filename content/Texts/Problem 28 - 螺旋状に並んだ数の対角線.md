>[!memo] [Problem 28](http://projecteuler.net/problem=28) 「螺旋状に並んだ数の対角線」
> 1から初めて右方向に進み時計回りに数字を増やしていき, 5×5の螺旋が以下のように生成される:
> 
> |   |   |   |   |   |
> |---|---|---|---|---|
> |==21==|22|23|24|==25==|
> |20|==7==|8|==9==|10|
> |19|6|==1==|2|11|
> |18|==5==|4|==3==|12|
> |==17==|16|15|14|==13==|
> 
> 両対角線上の数字の合計は101であることが確かめられる.
> 
> 1001×1001の螺旋を同じ方法で生成したとき, 対角線上の数字の和はいくつか?

各螺旋ごとにどの数字が新しく対角線上に現れるかを調べると、以下のようになる。
- (1x1): 1
- (3x3): 3 5 7 9
- (5x5): 13 17 21 25
- (7x7): 31 37 43 49

螺旋のマスが奇数であれば、対角線上の数字はすべて奇数になる。また、螺旋の右上の数字はかならずマス数の二乗(3x3=9, 5x5=25, 7x7=49)になる。

つまり、奇数 $i$ （ただし $3 \leq i \leq  螺旋の大きさn$）ごとに、対角線上の数字の増分 $\sum^{3}_{k=0}i^2 - k(i-1)$ を求めて、それらを足し合わせればいい。意外と楽な問題。

……なんて甘く考えてたら、LLMから「$\sum^{3}_{k=0}i^2 - k(i-1)$ はそのまま展開して、 $4i^2 - 6(i-1)$ と置いた方が計算量減るで」と言われた。私は論理の組み立てが甘い。

## 学んだこと
- 計算できるところはあらかじめ計算しておけ

## 自分が書いたコード
- $\sum^{3}_{k=0}i^2 - k(i-1)$ は`(add-diagonals n)`として実装
	- `n = 1`と`n = 2`は例外処理として場合分け

```racket
;; solve-28: Natural -> Natural
;; n x nの螺旋の対角線上にある数字の和を求める
(define (solve-28 n)
  ;; add-diagonals: Natural -> Natural
  ;; 該当マスにおける対角線上の追加ぶんを求めて、その合計値を出力
  (define (add-diagonals n)
    (cond [(= n 1) 1]
          [(even? n) 0]
          [else
           (define start (* n n))
           (define step (- 1 n))
           (define end (- (+ start (* 3 step)) 1))

           (for/sum ([i (in-range start end step)])
             i)]))
  
  (for/sum ([i (in-range 1 (+ 1 n) 2)])
    (add-diagonals i)))
```

## LLMによる改善案
- `(add-diagonals)`は`(layer-sum)`に名前を変更
	-  $4i^2 - 6(i-1)$ で実装
- `n = 1`、`n = (偶数)`の分岐を削除
	- `n = 1`の場合は、合計値に1を足せばOK

```racket
;; solve-28: Natural -> Natural
;; n x nの螺旋の対角線上にある数字の和を求める
(define (solve-28 n)
  ;; layer-sum: Natural -> Natural
  ;; 一辺の長さがnの層で追加される対角線上の数字を合計して出力
  (define (layer-sum n)
    (- (* 4 (* n n)) (* 6 (- n 1))))
  
  (+ 1
     (for/sum ([i (in-range 3 (+ 1 n) 2)])
       (layer-sum i))))
```
