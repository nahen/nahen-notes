>[!memo] [Problem 16](http://projecteuler.net/problem=16) 「各位の数字の和」
> $2^{15} = 32768$ であり, 各位の数字の和は $3 + 2 + 7 + 6 + 8 = 26$ となる.  
> 同様にして, $2^{1000}$ の各位の数字の和を求めよ.

まずは、他の2の累乗だとどういう結果になるか確認する。……のだが、法則性がまったくわからない。 $f(n) = f(n-1)+f(n-1)$ に落とし込めそうなのだが、$2^4,2^9, 2^{13}, 2^{16}$で$f(n-1)$が変化する条件がわからない。
- $2^1 = 2, 2^2 = 4, 2^3 = 8$
- $2^4 = 16 = 1 + 6 = 7 = 1 + 6$
	- 8+8=16。各位の数字の和が16となる2桁の最小値は79。
		- それ以下なので1+6に分ける
- $2^5 = 32 = 3+2 = 5 = 1 + 4$
	- 7+7=14。各位の数字の和が14となる2桁の最小値は59。
		- それ以下なので1+4に分ける
- $2^6 = 64 = 6+4 = 10 = 5+5$
	- 5+5=10。各位の数字の和が10となる2桁の最小値は19。なのでそのまま
- $2^7 = 128 = 1+2+8 = 11 = 10 + 1 + 0$
	- 10+10=20。各位の数字の和が20となる3桁の最小値は299。
		- それ以下なので10+1+0=11に分ける
	- 11となる3桁の最小値は119なのでそのまま
- $2^8 = 256 = 2+5+6=13 = 11 + 1 + 1$
- $2^9 = 512 = 5+1+2 = 8 = 1 + 3 + 1 + 3$
	- 13+13=26。各位の数字の和が26となる3桁の最小値は899。
		- それ以下なので13+1+3=17に分ける
	- 各位の数字の和が17となる3桁の最小値は179）
- $2^{10} = 1024 = 1+0+2+4 = 7 =1+6$
- $2^{11} = 2048 = 2+0+4+8 = 14 = 7+7$
- $2^{12} = 4096 = 4+0+9+6 = 19 = 14+1+4$
- $2^{13} = 8192 = 8+1+9+2 = 20 = 1+9+1+9$
- $2^{14} =16384 = 1+6+3+8+4 = 22 = 20 + 2+0$
- $2^{15} = 32768 = 3+2+7+6+8 = 26 = 22 + 2 + 2$
- $2^{16} = 65536 = 6+5+5+3+6 = 25 = ????$

これは数学の問題ではなく、プログラミング的な問題なのかも？　つまり、各桁をどうやって取得して足していくか、という問題。手軽なのは、計算結果を文字列として1文字ずつ分解して、その文字を足し合わせていく。でもそれだと、$2^{1000}$なんて巨大数を処理できない言語はどうしたらいいんだ？

## 学んだこと
- `first`と`car`、`rest`と`cdr`は同じ
	- `(first lst)` = `(car lst)`
	- `(rest lst)` = `(cdr lst)`
	- `car`と`cdr`は昔の慣用

## 自分が書いたコード
- 素直に巨大数を文字列にして、各文字列を数値に変換したうえで足し合わせる
	- でも本来Project Eulerが求めた回答ではないと思う

```racket
(define (power-digit-sum n)
  (define lst (string->list (number->string n)))
  (apply +
         (map (lambda (c) (string->number (string c)))
              lst)))
```

## LLMによる改善案
- リストを作らないぶん、コードの見た目がスッキリする

```racket
(define (power-digit-sum n)
  (for/sum ([c (in-string (number->string n))])
    (string->number (string c))))
```

## 別解
- $2^0 = 1$を初期値として、各位の数値に2を掛けつづける
- 巨大数としてではなく、各位の数値を収めたリストとして扱う
	- `65535`ではなく、`'(6 5 5 3 5)`

```racket
;; power-digit-sum : Integer -> Integer
;; 2^nから各位の数字の和を出力する
(define (power-digit-sum n)
  ;; 注意: lstには逆順で入れる（ex. 1024 -> '(4 2 0 1)）
  (define (loop lst carry acc)
    (cond [(empty? lst)
           (if (> carry 0)
               (cons carry acc)
               acc)]
          [else
           (let* ([x (+ (* (first lst) 2) carry)]
                  [digit (remainder x 10)]
                  [new-carry (quotient x 10)])
             (loop (rest lst) new-carry (cons digit acc)))]))
  
  (define (double-digits digits)
    (loop (reverse digits) 0 '()))

  (define digits
    (for/fold ([d '(1)]) ([i (in-range n)])
      (double-digits d)))

  (for/sum ([d digits]) d))
```
