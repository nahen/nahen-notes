私が[[🧰Anki]]で自作した英英辞典例文集のデッキには、以下の18種類のフィールドがある。さすがに細かく分けすぎかもしれない。

| ------- | ------------------------------- | ------------------------------------------------------------------------------------------ |
| ID      | ノートのID                          | LDOCE-0001                                                                                 |
| 英語の例文   | 英英辞典から取得した英語の例文                 | The dentist could fit you in later in the week.                                            |
| 例文の音声   | 例文の音声ファイル名                      | p008-001480657.mp3                                                                         |
| 例文の日本語訳 | 和英辞典から取得、またはLLMが生成した日本語訳        | 歯医者は週の後半なら予約が取れる．                                                                          |
| 英単語     | 例文で使っている英単語                     | lat‧er                                                                                     |
| 別の表現    | 英英辞典に"also"として載っていた別の表現         | （英単語が"save"の場合）(also save up)                                                              |
| 発音記号    | 英英辞典から取得した英単語のIPA発音記号           | ˈleɪtə $ -ər                                                                               |

## テンプレートの設定例（表面）
![[表面テンプレート.png]]

表面テンプレートに表示するフィールドは、「英語の例文」「英文の音声」の2種類のみ。`[sound:{{例文の音声}}]`とすると、音声ファイルがAnkiのメディアフォルダ内に存在していれば、音声が流せるようになる。[^hisuisho]

[^hisuisho]: 実はこのやり方は非推奨である。[Anki公式マニュアル](https://wikiwiki.jp/rage2050/2.0/CardsAndTemplates)によれば、テンプレート上のメディアファイルにフィールド名を組み込む方法（[フィールド参照](https://wikiwiki.jp/rage2050/2.0/CardsAndTemplates#field-references)）は動作が保証できないとされる。

## テンプレートの設定例（裏面）
![[裏面テンプレート.png]]

残りのフィールドはすべて裏面に表示する。一部のフィールドは条件付き置換[^jyouken]を使って、値が存在すると場合のみ表示するようにしている。

[^jyouken]: フィールドが空白、または空白でない場合に特定の文字列やフィールド、HTMLを表示する機能。たとえばテキストを`{{#FieldName}}テキスト{{/FieldName}}`のように囲むことで、FieldNameに値が存在する場合のみ、テキストを表示できる。詳しくは[Anki日本語マニュアル Wiki\*](https://wikiwiki.jp/rage2050/2.0/CardsAndTemplates#conditional-replacement)を参照。
