[[🧰Anki]]で不変ノートを作る場合は、Ankiノートのデータをフィールド[^field]に、表示用のHTMLタグをテンプレートに分けて載せよう。たとえば、[[💡IDフィールドを追加するとノートの作成・修正が簡単になる|IDフィールドを追加するだけでも、Ankiノートの作成・編集が楽になる]]。

[^field]: Ankiのカードに表示する項目群のこと。多くのノートタイプでは、フィールドは表面`{front}`と裏面`{back}`の2種類のみ。フィールドだけでは利点はないが、テンプレートと組み合わせると、ノートの管理が楽になる。

- [[🦾英英辞典例文集のフィールド設定例]]

## 悪例：フィールドに装飾も加える
ひとつのフィールドに複数の情報を入れたい場合、テキストを装飾するHTMLタグも含めて、フィールドに記入する必要がある。

たとえば、私が作った[[🦾英英辞典例文集のフィールド設定例|英英辞典例文集のフィールド18種類]]を無理やり「表面」「裏面」の2種類に統合すると、以下のようになる。Ankiノートを作るうえでは悪例。

### 表面
```html
<span>{{英語の例文}}</span> [sound:{{例文の音声}}]
```

### 裏面
```html
{{例文の日本語訳}}
<div style="padding-top: 2em">
	<span style="font-weight: bold; color: rgb(255, 26, 26);">{{英単語}}</span>
{{#別の表現}}
  <span>{{別の表現}}</span>
{{/別の表現}}
{{#発音記号}}
	<span>/{{発音記号}}/</span>
{{/発音記号}}
	<span style="font-weight: bold; color: rgb(114, 255, 114);">{{品詞}}</span>
{{#活用}}
	<span>{{活用}}</span>
{{/活用}}
{{#文法}}
  <span style="font-weight: bold; color: rgb(114, 255, 114);">{{文法}}</span>
{{/文法}}
{{#国}}
	<span style="font-style: italic; color: rgb(128, 162, 209);">{{国}}</span>
{{/国}}
{{#用語}}
	<span style="font-style: italic; color: rgb(255, 114, 255);">{{用語}}</span>
{{/用語}}
{{#イギリス発音}}
[sound:{{イギリス発音}}]
{{/イギリス発音}}
{{#アメリカ発音}}
[sound:{{アメリカ発音}}]
{{/アメリカ発音}}
</div>
<div>
	<span>{{定義}}</span>
{{#類義語}}
		<span style="padding: 3px; background-color: rgb(193, 171, 0);">類義語</span>
		<span style="font-weight: bold;">{{類義語}}</span>
{{/類義語}}
{{#対義語}}
		<span style="padding: 3px; background-color: rgb(193, 171, 0);">対義語</span>
		<span style="font-weight: bold;">{{対義語}}</span>
{{/対義語}}
{{#関連語句}}
	<span style="color: rgb(51, 125, 255);">{{関連語句}}</span>
{{/関連語句}}
</div>
```
