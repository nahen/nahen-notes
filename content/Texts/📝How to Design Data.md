title: 📝How to Design Data

プログラミングでデータの定義を体系的に行う方法。現実のドメイン上にあるオブジェクトをコンピュータ上のデータに変換し、対応づけるための手法。ここで作られたデータ定義は、[[📝How to Design Function]]で[[📝How to Design Function#6. テストコードをクリアできるように関数の処理を書く|関数のテンプレート]]を作る土台となる。

1. 新しいデータの名称（≒現実ドメイン上の名称）と型を決める
2. データと現実のオブジェクトがどのように対応づいているかを表記する
3. データの例を変数として定義する
4. データの型からテンプレートを選んで貼り付ける

ここでは、簡単な例としてネコの名前を作るとする。あなたが犬派であれば、イヌの名前でもよい。

>[!caution]
>コード例にPythonを使っていますが、Pythonを日々扱う方からするとコードやコメントの書き方が不自然かもしれません。これは、『[Systematic Program Design Recipes](https://cs110.students.cs.ubc.ca/reference/design-recipes.html)』で使われている言語（Beginning Student Language）を、むりやりPythonの形に落とし込んでいるためです。ご容赦ください。

##  1. 新しいデータの名称と型を決める
```python
class CatName:
	""" 
	CatName: str
	"""
```

通常、ネコの名前は「タマ」「ミケ」「ぬっこ」といった文字列で表される。数字の名前（たとえば「123番」）であっても、文字列で表すことができるので問題はない。Pythonでは、文字列の型はstr。

変数の名前は、データが表すものを過不足なく伝えられるものにしよう。ここで横着して「Name」や「CN」と表してしまうと、他のプログラマーと未来の自分が困ってしまう。

## 2. データと現実のオブジェクトの対応づけを表記する
```python
class CatName:
	""" 
	CatName: str
	ネコの名前
	"""
```

変数名だけで表現しきれない場合もある。そのときはこの変数が何を表しているかを一行で説明する。

## 3. データの例を定数として定義する
```python
class CatName:
	""" 
	CatName: str
	ネコの名前
	"""
	NAME_1: str = "タマ"
```

データの例を定数で表記する。[^fix]今回のネコの名前の場合、「文字列が入る」ことが伝わればよいので、例は1つだけでかまわない。

[^fix]: 残念ながら、Pythonでは定数を宣言できない。なので、変数名を大文字で表記してアンダースコアで繋ぐことで「これは固定値として扱ってね」と暗に伝える。

ここでは、ネコの名前としてあり得る文字列（正常系）のことだけ考える。あり得ない名前（異常系）については考えない。

## 4. データの型から関数のテンプレートを作る
```python
class CatName:
	""" 
	CatName: str
	interp. ネコの名前
	"""
	NAME_1: str = "タマ"
	
	def fnForCatName(self, name):
		#... name
		pass
	
```

ここで、[[📝How to Design Function]]で用いる関数のテンプレートを作る。以下の表から条件に当てはまるセルを探して、そこに書かれているテンプレートをそのまま貼り付ければよい。

ここで作った関数のテンプレートは、のちに`CatName`を扱う関数の土台となる。

| データの種類                                                       | データ例              | 条件文                                                       | テンプレート  |
| ------------------------------------------------------------ | ----------------- | --------------------------------------------------------- | ------- |
| atomic non-distinct<br>ひとつの文字列、数値、真偽値等で表せるもののうち、内容が確定していないもの | int, str, bool    | `type(x) is int`<br>`type(x) is str`<br>`type(x) is bool` | ... x   |
| atomic distinct<br>ひとつの文字列、数値、真偽値で表せるもののうち、内容が確定しているもの       | "文字列", True, None | `x == "文字列"`<br>`x`<br>`x is None`                        | ...     |
| Iterater, Enumerations<br>文字列、数値が複数含まれる配列                    | \[1, 2, 3\]       | -                                                         | switch文 |
