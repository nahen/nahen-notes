### 0. 作る関数を決める
関数を作り始める前に、まず自分が作りたい関数を決めておく。今回は簡単な例として、入力した値を2倍にする関数を作る。

- [[💡関数の基本要素3つは入力、処理、出力]]

### 1.  入力・出力値の型（シグネチャ）を決める
```python
# float -> float
```
入力値と出力値に使う型（シグネチャ[^signature]）を決めて、コメントに書く。プログラミングで使う型は言語によって異なるが、Pythonの場合は大雑把に分けて以下の型になる。

[^signature]: 「プログラミングの分野では、関数やメソッドの名前、引数の数やデータ型、返り値の型などの組み合わせのことをシグネチャという。」（[IT用語辞典 e-Words『シグネチャ』](https://e-words.jp/w/%E3%82%B7%E3%82%B0%E3%83%8D%E3%83%81%E3%83%A3.html)より）

| データの種類 | Pythonでの型名 |
| ------ | ---------- |
| 数字（整数） | int、long   |
| 数字（小数） | float      |
| 文字列    | str        |
| 真偽値    | bool       |
| 値なし    | None       |

今回は「入力した値を2倍にする」関数なので、入力値・出力値はいずれも数字になる。入力値が小数であっても計算できるようにしたいので、今回は入力値・出力値ともに`float`型にする。

### 2. 処理内容を自然言語で書く
```python
# float -> float
# 入力した値を2倍にする
```

関数が行う処理内容、つまり「なんやかんや」を自然言語（私の場合は日本語）で文章にする。すぐにコードを書きたい気持ちを抑えて、まずは自分の口で関数の処理内容を説明する。

文章の粒度は、処理内容が過不足なく説明できており、かつ一行または一言で説明できているぐらいがよい。今回は簡単な処理なので、「入力した値を2倍にする」で十分だ。

関数の処理内容を一言で説明できない場合は、おそらく関数で実行する処理が多すぎるか、自身が処理内容をよく理解できていない。

### 3. ダミー関数（スタブ）を作る
```python
# float -> float
# 入力した値を2倍にする

def double(x: float) -> float:
	return 0
```

入力値・出力値の型と処理内容を固めたら、ダミー関数（スタブ[^stub]）を作る。ダミー関数は入力値を受け取るものの、何も処理せずにテキトウな出力値を返す。ここではまだ、関数の処理内容については考えない。

[^stub]: 「ソフトウェアテストで単体テストや結合テストを行う際、テスト対象モジュールから呼び出されるモジュールの代わりに出力結果を返す簡易プログラムのこと。」（[情報システム用語事典『テストスタブ』](https://www.itmedia.co.jp/im/articles/0601/17/news094.html)より）

### 4. テストコードを書く
```python
# float -> float
# 入力した値を2倍にする

def double(x: float) -> float:
    """
    関数を実行した時に想定される結果をこの中に書く
    1. 入力値: 2 -> 出力値: 4
    2. 入力値: 4.8 -> 出力値: 9.6
    3. 入力値: -2 -> 出力値: -4
    >>> double(2)
    4
    >>> double (4.8)
    9.6
    >>> double(-2)
    -4
    """
    return 0

if __name__ == '__main__':
    import doctest    # <- doctestモジュールを使うことを宣言する
    doctest.testmod() # テストコードを実施する
```

ダミー関数を作ったら、次にテストを追加する。ここでは手軽にテストが書けるように、`doctest`モジュールを使っている。

テストとは、関数が自分の想定どおりに実行できているかを確認する工程だ。今回の場合は、入力値がきちんと2倍になることを確認する。

上記のPythonコードの例では、以下3つのテストを用意した。
- 入力値が2であれば、出力値は4
- 入力値が4.8であれば、出力値は9.6
- 入力値が-2であれば、出力値は-4

本当は、関数のコードとテストコードはそれぞれ別のファイルに分けて書いたほうがいい。しかし、 ~~Pythonでのテストコードの書き方をよく知らないうえ、~~ 手軽にコードを書きたいので、今回はひとまとめにして書いている。

### 5. テストコードを実行する
テストを書き終えたら、書いたコードを一度コンソールで実行する。コードに不自然な点がなければ、3つのテストの実行結果がコンソールに表示されるだろう。

実際の実行結果は以下のとおり。コンソールが「テストが3つとも想定どおりになっとらんぞ」と怒っているが、今はその状態で問題ない。

### 6. テストコードをクリアできるように関数の処理を書く
```python
# float -> float
# 入力した値を2倍にする

def double(x: float) -> float:
    """
    >>> double(2)
    4
    >>> double (4.8)
    9.6
    >>> double(-2)
    -4
    """
    return x * 2    # <- 処理内容を書く

if __name__ == '__main__':
    import doctest
    doctest.testmod()
```

ここでようやく、処理内容をコードに落とし込む。今回は「入力した値を2倍にする」関数なので、返り値を`0`から`x * 2`に置き換えるだけでいい。

### 7. すべてのテストをクリアしたら、できあがり！
コードを書き終えたら、もう一度書いたコードをコンソールで実行する。以下のように、`***Test Failed***`等のメッセージが出なくなれば、関数のできあがり。

```
** Process exited - Return Code: 0 **
Press Enter to exit terminal
```
