ExcelやGoogleスプレッドシート上で[[🧰Anki]]の不変ノートを作る場合は、IDフィールドを新しく追加しよう。IDフィールドを用意しておくと、その後のノートの追加・修正が楽になる。

## 通常は最初のフィールドがID代わりになる
>[!cite] [インポート (Importing) - Anki日本語マニュアル Wiki](https://wikiwiki.jp/rage2050/2.0/Importing#:~:text=%E3%83%86%E3%82%AD%E3%82%B9%E3%83%88%E3%83%95%E3%82%A1%E3%82%A4%E3%83%AB%E3%81%AE%E3%82%A4%E3%83%B3%E3%83%9D%E3%83%BC%E3%83%88%E6%99%82%E3%80%81Anki%E3%81%AF%E3%83%8E%E3%83%BC%E3%83%88%E3%81%8C%E5%90%8C%E4%B8%80%E3%81%A7%E3%81%82%E3%82%8B%E3%81%8B%E5%90%A6%E3%81%8B%E3%81%AE%E6%B1%BA%E5%AE%9A%E3%81%AB%E6%9C%80%E5%88%9D%E3%81%AE%E3%83%95%E3%82%A3%E3%83%BC%E3%83%AB%E3%83%89%E3%82%92%E7%94%A8%E3%81%84%E3%81%BE%E3%81%99%E3%80%82)
>テキストファイルのインポート時、Ankiはノートが同一であるか否かの決定に最初のフィールドを用います。

通常、Ankiはノートを見分ける際に、最初のフィールドの値を見ている。いわば最初のフィールドがIDの代わりになる。

## 単純な英単語帳ノートを作る場合
たとえば、単純な英単語帳ノートをスプレッドシート上で作るとする。表面フィールドに英単語、裏面フィールドに単語の日本語訳を書く（下の表のように）。この場合、最初の表面（英単語）フィールドがID代わりとなる。

| 表面        | 裏面        |
| --------- | --------- |
| important | 重要な〜、大切な〜 |

### 入力値を間違えると修正が面倒になる
ここでうっかりノートを作り間違えたとしよう。表面を「inportant」とつづり間違えたまま登録してしまった。この場合、ノートの誤りはAnkiアプリ上で訂正するしかない。

| 表面        | 裏面        |
| --------- | --------- |
| inportant | 重要な〜、大切な〜 |

「表面のテキストを修正してもう一度インポートすればよいのでは？」と考える人もいるだろう。そこで、スプレッドシート上で表面セルのテキストを修正して、もう一度Ankiにインポートしたとする。

ところが、インポート結果は下の表のようになる。「inportant」が残ったまま「important」を新しく追加している。これは、表面フィールドの内容が違うせいで、Ankiがそれぞれを別のノートだとみなしてしまうためだ。

| 表面        | 裏面        |
| --------- | --------- |
| inportant | 重要な〜、大切な〜 |
| important | 重要な〜、大切な〜 |

## 「Anki上で訂正できるなら問題ないのでは？」
もちろん、問題はない。誤ったノートを検索して探し出して、内容を修正すればよい。しかし、デッキにノートが数千枚以上ある場合や、そもそも自分が表面フィールドをどう書き損じたか覚えていない場合、しらみつぶしに調べる方法では時間がかかる。

なにより、スプレッドシート上でAnkiノートを作っているのに、訂正はAnki上でないとできないというのは非効率的だ。私はノートの作成も訂正も、スプレッドシート上で完結させたい。

## IDフィールドを追加すると修正が楽になる

| ID         | 表面        | 裏面        |
| ---------- | --------- | --------- |
| EIGO-00001 | important | 重要な〜、大切な〜 |

Ankiアプリでないと訂正できない問題は、IDフィールドを追加すればカンタンに解決できる。IDの採番は、番号が被らなければどんな方法でもかまわない（私は上の表のように、アルファベットの固定値とハイフン、数字の連番の組み合わせで割り振っている）。

[[💡IDフィールドを追加するとノートの作成・修正が簡単になる#通常は最初のフィールドがID代わりになる|先述の通り]]、Ankiはインポート時、最初のフィールドの値をもとにノートを見分けている。なので最初のフィールドを、値が変わるかもしれない表面フィールドから、値が絶対に変わらないIDフィールドに変更すればよい。

あとはスプレッドシート上で間違えた箇所を修正して、もう一度インポートし直す。修正前後でIDは変わっていないので、Ankiは既存のノートに変更を反映してくれるはずだ。
