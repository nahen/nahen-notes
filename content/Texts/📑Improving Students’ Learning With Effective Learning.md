学生が使う学習方法10個の紹介と、その効果についてまとめたメタ研究。心理学の論文を数多く分析して、それぞれの勉強法の効果の是非を調べている。

## 取り上げられた学習法とその有用性

| 勉強法               | 有用性 | 理由                       |
| ----------------- | --- | ------------------------ |
| [[📝精緻化質問]]       | 中   | 上級者ほど効果的                 |
| 自己説明              | 中   | 上級者ほど効果的                 |
| 要約                | 低   | トレーニングが必要なうえ、学習に寄与するかは疑問 |
| ハイライト             | 低   | 効果はあるが、模擬テストの方がより効果的     |
| キーワード記憶法          | 低   | 覚えるのに効果的だが、分野が限られる       |
| イメージ想起            | 低   | 覚えるのに効果的だが、分野が限られる       |
| 再読                | 低   | 初心者でも使えるが、時間がかかりすぎる      |
| [[📝想起練習\|模擬テスト]] | 高   | 初心者から上級者まで、どの分野でも手軽に使える  |
| [[📝間隔練習]]        | 高   | 初心者から上級者まで、どの分野でも手軽に使える  |
| [[📝インターリーブ]]     | 中   | 初心者には不向きだが、数学で特に効果的      |

## 有用性≠効果量
ここでいう有用性とは、効果がある対象の広さを指す。有用性が高いとは、知識の有無にかかわらず、どんな学問分野であっても、子供からお年寄りまで効果がある、という意味である。必ずしも、効果量が高いという意味ではないし、時間対効果（コスパ）が良いという意味でもない[^low]。

[^low]: 一方で、有用性が低い勉強法はある意味、コスパが悪いと解釈することもできる。たとえば再読は初心者に効果的だが、時間がかかりすぎる。キーワード記憶法も同じく、効果的なキーワードを思いつくのに時間がかかる。そのうえ、使える学問範囲が狭い。

たとえば、有用性が中程度と評価された勉強法の中には、模擬テストと同じくらい効果的なものもある。ただし以下のために、有用性が限られている。
- 上級者には効果的だが、初心者には効果が薄い（自己説明、[[📝精緻化質問]]）
- 効果的だが、有用性を保証するには論文が少ない（[[📝インターリーブ]]）
