「数の暴力[^tyranny]」を防ぐために、グレン・ワイル氏が考案した投票様式。各投票者は一律に数十〜数百のポイントを持つ。そして、入れたい票数（$n$票）の二乗ぶんのポイント($n^2$ポイント)を消費することで、複数の候補にそれぞれ票を入れることができる。

[^tyranny]: 支持者が多いことを利用して、多数派が少数派を排除・抑圧すること。多数者の専制とも。多数決の欠点。

台湾の総統杯ハッカソン[^sotosai]でこの投票様式が使われ、それを[[オードリー・タン]]氏が伝えたことで知られるようになったらしい。

[^sotosai]: 総統盃黒客松。台湾政府公認（？）で2018年から毎年開催されているハッカソン。オープンデータを利用して、テーマに沿った社会問題を解決するソリューションを制限時間内に提案する。

Quadratic Votingと似た概念にQuadratic Fundingがある。こちらは票を入れる際に、ポイントではなく現金を消費する。実はこちらが先。

## 票ごとのポイント消費量の例

| 消費ポイント | 票への換算           | 票数  |
| ------ | --------------- | --- |
| 1      | $\sqrt{1}=1$    | 1   |
| 4      | $\sqrt{4}=2$    | 2   |
| 9      | $\sqrt{9}=3$    | 3   |
| 16     | $\sqrt{16} = 4$ | 4   |
| 25     | $\sqrt{25}=5$   | 5   |
| …      | …               | …   |

## 利点：少数派の意見が多数派と同列になる
従来の投票の多くは、一人一票制だ。選べる選択肢はひとつだけで、入れられる値もゼロかイチしかない。一方で、Quadratic Votingは自分が関心をもつものすべてに重みをつけて投票できる。

たとえば、ある事柄に対して「1人が強く支持する選択肢」と「10人が弱く支持する選択肢」があるとする（この2つ以外の選択肢も存在するとしよう）。一人一票制の場合、前者は1票、後者は10票となり、10票の入った後者が採択される。

しかしQuadratic Votingの場合、このふたつの選択肢に対する票が同数になる可能性がある。たとえば、1人が前者の選択肢に100ポイントを費やして10票入れ、10人が後者の選択肢にそれぞれ1ポイント費やして合計10票入れたとする。この場合、両者とも票数は10票となり、一人一票制では生まれた票数の差がなくなる。

## 欠点：買収に弱い
Quadratic Votingは、ふたつの前提から成り立っている。これらの前提が崩れると、Quadratic Votingの利点がなくなる。

- 一人一人に割り当てられるポイントが均等である
- ポイントの受け渡しができない

まず、一人一人に割り当てられるポイントは同じでなければならない。[^1]特定の個人にだけ他の人よりも多くポイントを割り振ってしまったら、その人の意見が投票で有利になってしまう。

そして、各人が投票に使えるポイントは、自分に割り振られたぶんだけだ。自分のポイントを他人に渡したり、逆に他人からポイントをもらったりすることはできない。

しかし、Quadratic Votingにはいちばん気をつけるべき脅威がある。それは買収ーー投票する権利の売買だ。これはポイントの譲渡よりも恐ろしく、投票システムのセキュリティ強化だけでは防げない。

Quadratic Votingはその仕組み上、全員に割り振られるポイント数が同じであっても、投票者が多いほど票数が多くなる。以下の表を見ると、消費ポイントの合計値が同じであっても、投票者数が多いと最大票数も増えることがわかる。1人が200ポイントを費やすよりも、4人が50ポイントを費やすほうが、票数は2倍になる。

| 投票者数 | 一人当たりの消費ポイント | 最大票数                                           |
| ---- | ------------ | ---------------------------------------------- |
| 1人   | 200          | $\sqrt{200} = 10\sqrt{2} = 14.1421\dots$       |
| 2人   | 100          | $\sqrt{100}\cdot2=10\cdot2=20$                 |
| 4人   | 50           | $\sqrt{50}\cdot4=5\sqrt{2}\cdot4=28.2842\dots$ |
| 8人   | 25           | $\sqrt{25}\cdot8=5\cdot8=40$                   |

つまり、制度をハックしたい個人・団体からすれば、ポイントをお金で買うよりも、そのお金で有権者を抱え込むほうがお得になる。有権者を抱え込んでしまえば、その個人・団体に有利な案を通して、不利な案を通さないようにできる。そうなれば、Quadratic Votingは形骸化してしまう。
