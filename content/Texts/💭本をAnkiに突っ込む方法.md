[[📝Incremental Reading]]を[[🧰Anki]]で実践する手順のひとつ。まずはAnkiで読むための文章を用意する。

## 読みたいテキストを用意する
### 1. Ankiに読書用のデッキを新しく作る
#### (1) デッキの設定
まずは読書用のデッキを新しく作る。読書デッキのオプションのうち、以下3項目の設定値を変更している。特に、[[#表示順序]]は必ずこの設定値にしたい。

- 一日の上限
- 表示順序
- 兄弟関係のカードの非表示

以降の表では、デフォルトから変更した箇所にハイライトを引いている。

##### 一日の上限

| オプション                  | 設定値     |
| ---------------------- | ------- |
| 一日の新規カード導入枚数の上限        | ==30==  |
| 一日の復習枚数の上限             | ==300== |
| 復習枚数の上限に関係なく新規カードを導入する | ON      |
| 上限をメインデッキから適用          | OFF     |

新規カード・復習カードの上限値は各々で好きな値を設定する。できる限り、1日で無理なく消化できる量にするとよい。（私の場合、新規上限が30枚、復習上限が300枚）

なお、Ankiユーザの中には「[新規も復習も上限9999！](https://leananki.com/best-settings/)」という猛者もいる。私も一度試したが、読書デッキには合わなかった。

##### 表示順序

| オプション名                          | 設定値                 |
| ------------------------------- | ------------------- |
| 新規カードを集める順序                     | ==位置（新規カード番号）の昇順==  |
| 集めた新規カードを並べる順序                  | ==集めたときの順序==        |
| 新規カード表示のタイミング                   | 復習に混ぜ込む             |
| 日をまたいだステップの習得中（再習得中）カード表示のタイミング | 復習に混ぜ込む             |
| 復習カードを並べる順序                     | 期日超過日数が多い順→同日数はランダム |

新規カードの順序は、それぞれ「位置（新規カード番号）の昇順」「集めたときの順序」としている。 **一度目の読書はいつもと同じように、上から下へと線形に読みたいからだ。**

お試しで新規カードの順序を「ランダム（ノート単位）」に設定して、新規カードをランダムに並べて読んでみたことがある。テキスト全体の意図がつかめなくなるので、避けたほうがいい。

##### 兄弟関係のカードの非表示

| オプション名                                  | 設定値    |
| --------------------------------------- | ------ |
| 兄弟関係の新規カードを同じ日に表示しない                    | ==ON== |
| 兄弟関係の復習カードを同じ日に表示しない                    | ==ON== |
| 兄弟関係の習得中カードで、ステップが日をまたいでいる場合は、同じ日に表示しない | OFF    |

兄弟関係のカードとは、同じノートから作られた複数のカードを指す。私は新規・復習ともONにしている。同じ日に同じ文面を何度も読まされるのは好きではない。

#### (2) フィールドは2種類だけ
読書カードを手軽に穴埋めカードに転用できるように、フィールドは2種類に絞る。詳しくは「[[🦾可変ノートはフィールドを2つに絞る]]」を参照。

#### (3) カードテンプレートの準備
デフォルトのテンプレートは長い文章を読むには不便だ。なので以下のようにCSSを設定する。CSSは「ツール」→「ノートタイプの管理」→「カード」→「テンプレート: スタイル」から設定できる。

```css
.card {
  /* 文字の大きさ */
  font-size: 18px;
  /* 文字配置: 左寄せ */
  text-align: left;
  /* 行間を少し広げる */
  line-height: 2.25rem;
  /* カーニングを適用する */
  font-kerning: normal;
}
```


### 2. Web記事をインポートする
#### (1) Web記事のHTMLを整形する
>[!info] 
>もっと良い手順をご存知の方は、教えていただけると幸いです！

Web記事をAnkiで読む形式に整える。私は以下の工程で実施している。
1. HTMLで取り込む
2. HTMLをマークダウン形式に変換してもらう
3. 変換したマークダウンをさらにHTMLに変換する

マークダウンに変換するのは、Web記事にある余分なタグを取り除くため。

##### ア. 読みたい部分のHTML要素を取得する
ブラウザの開発者モードを使って、取り込みたい文章のHTMLをコピーする。

##### イ. コピーしたHTMLをマークダウンに変換する
コピーしたHTMLをマークダウンに変換する。
- [HTML to Markdown Converter](https://htmlmarkdown.com/)

##### ウ. マークダウンをHTMLに変換する
Ankiはマークダウン形式に対応していない。なので、マークダウンをもう一度HTMLに変換する。HTMLのプレビューで確認して、表示のおかしい部分があれば修正する。また、Webページ内にまぎれこんだ広告欄など、不要な情報はこの段階で取り除いてもよい。
 - [Free Markdown to HTML Converter](https://markdowntohtml.com/)

#### (2) HTMLをスプレッドシートに貼り付け
変換できたHTMLをGoogle スプレッドシートに貼り付ける。ここで文章を章・節・段落ごとにまとめる。

#### (3) 2列目に情報元を記述
#### (4) スプレッドシートからエクスポートする
#### (5) Ankiにインポートする

## まずはWeb記事から


- まずは読みたいテキストを用意する
	- 読書用のデッキを新しく作成する
		- 通常のデッキとは違う運用をするので区別した方がいいかも
	- テキストをインポートする
		- スプレッドシート（Excel、Google Spread Sheetなど）を用意する
			- 私はGoogle Spread Sheet
		- 最初は文章を章・節または段落ごとに分ける
			- 最初はざっくりとした機械的な分け方でOK
				- それでも長すぎる場合は、分割した章・節・段落からさらにざっくり分ける
		- 一列目
			- テキストを入れる
			- HTMLの場合
				- 不要なタグをクレンジングする
					- 私はマークダウン化→再度HTML化でクレンジングしている
					- MarkdownをHTML化するアドオンを入れてもいいかも
			- PDFの場合
				- テキストを拾うサービス等で文章を取得する
					- PDFから1ページずつ文章を貼り付けでもいいが、時間がかかる
		- 二列目
			- ここは個人の好み
				- 私は情報源などの情報を入れている
				- 面倒であれば空欄でもいい
- Webサイトや電子書籍といった電子媒体がいい
	- 文章のインポートが楽になる
