[[📝Incremental Reading]]を[[🧰Anki]]で実践する手順のひとつ。まずはAnkiで読むための文章を用意する。

## 読みたいテキストを用意する
### 1. 読書用のデッキを新しく作る
#### (1) デッキの設定
まずは読書用のデッキを新しく作る。読書デッキのオプションのうち、以下3項目の設定値を変更している。特に、[[#表示順序]]は必ずこの設定値にしたい。

- 一日の上限
- 表示順序
- 兄弟関係のカードの非表示

以降の表では、デフォルトから変更した箇所にハイライトを引いている。

##### 一日の上限
![[デッキ_1日の上限.png]]

| オプション                  | 設定値     |
| ---------------------- | ------- |
| 一日の新規カード導入枚数の上限        | ==30==  |
| 一日の復習枚数の上限             | ==300== |
| 復習枚数の上限に関係なく新規カードを導入する | ON      |
| 上限をメインデッキから適用          | OFF     |

新規カード・復習カードの上限値は各々で好きな値を設定する。できる限り、1日で無理なく消化できる量にするとよい。（私の場合、新規上限が30枚、復習上限が300枚）

Ankiユーザの中には「[新規も復習も上限9999！](https://leananki.com/best-settings/)」という猛者もいる。私も一度試したが、読書デッキには合わなかった。

##### 表示順序
![[デッキ_表示順序.png]]

| オプション名                          | 設定値                 |
| ------------------------------- | ------------------- |
| 新規カードを集める順序                     | ==位置（新規カード番号）の昇順==  |
| 集めた新規カードを並べる順序                  | ==集めたときの順序==        |
| 新規カード表示のタイミング                   | 復習に混ぜ込む             |
| 日をまたいだステップの習得中（再習得中）カード表示のタイミング | 復習に混ぜ込む             |
| 復習カードを並べる順序                     | 期日超過日数が多い順→同日数はランダム |

新規カードの順序は、それぞれ「位置（新規カード番号）の昇順」「集めたときの順序」としている。 **一度目の読書はいつもと同じように、上から下へと線形に読みたいからだ。**

お試しで新規カードの順序を「ランダム（ノート単位）」に設定して、新規カードをランダムに並べて読んでみたことがある。テキスト全体の意図がつかめなくなるので、避けたほうがいい。

##### 兄弟関係のカードの非表示
![[デッキ_兄弟関係のカード.png]]

| オプション名                                  | 設定値    |
| --------------------------------------- | ------ |
| 兄弟関係の新規カードを同じ日に表示しない                    | ==ON== |
| 兄弟関係の復習カードを同じ日に表示しない                    | ==ON== |
| 兄弟関係の習得中カードで、ステップが日をまたいでいる場合は、同じ日に表示しない | OFF    |

兄弟関係のカードとは、同じノートから作られた複数のカードを指す。私は新規・復習ともONにしている。同じ日に同じ文面を何度も読まされるのは好きではない。

### 2. 読書用ノートタイプを新しく作る
![[ノートタイプ.png]]

デッキを作ったら、次に読書カード用のノートタイプを新規作成する。
「Anki」→「ツール」→「ノートタイプを管理」から、ノートタイプのダイアログを開く。追加するノートタイプは「基本」で問題ない。

![[ノートタイプ_ノートタイプの追加.png]]

なお、ノートタイプを新しく作る際、「追加」と「クローン」のどちらにするかを聞かれる。それぞれ以下の違いがある。しかし、ノートタイプを複製する点では同じなので、どちらを選んでも問題はない。
- デフォルトで用意しているノートタイプ：追加
- すでにコレクションに存在するノートタイプ：クローン

#### (1) フィールドは2種類だけ
読書カードを手軽に穴埋めカードに転用できるように、フィールドは2種類に絞る。詳しくは「[[🦾可変ノートはフィールドを2つに絞る]]」を参照。

#### (2) カードテンプレートの準備
デフォルトのテンプレートは長い文章を読むには不便だ。なので以下のようにCSSを設定する。CSSは「ツール」→「ノートタイプの管理」→「カード」→「テンプレート: スタイル」から設定できる。

```css
.card {
  /* 文字の大きさ */
  font-size: 18px;
  /* 文字配置: 左寄せ */
  text-align: left;
  /* 行間を少し広げる */
  line-height: 2.25rem;
  /* カーニングを適用する */
  font-kerning: normal;
}
```


### 3. Web記事をインポートする
#### (1) Web記事のHTMLを整形する
>[!info] 
>より良い手順をご存知の方は、教えていただけると幸いです！

Web記事をAnkiで読む形式に整える。私は以下の工程で実施している。
1. HTMLで取り込む
2. HTMLをマークダウン形式に変換してもらう
3. 変換したマークダウンをさらにHTMLに変換する

マークダウンに変換するのは、Web記事にある余分なタグを取り除くため。

##### ア. 読みたい部分のHTML要素を取得する
ブラウザの開発者モードを使って、取り込みたい文章のHTMLをコピーする。

##### イ. コピーしたHTMLをマークダウンに変換する
HTMLを手作業でマークダウンに置き換えるのは骨が折れる。なのでこの作業は既存サービスに任せる。
- [HTML to Markdown Converter](https://htmlmarkdown.com/)

##### ウ. マークダウンをHTMLに変換する
マークダウンに変換したはいいものの、Ankiはマークダウン形式に対応していない。[^markdown]なので、マークダウンをもう一度HTMLに変換する。

HTMLのプレビューで確認して、表示のおかしい部分があれば修正する。Webページ内に不要な広告などは、この段階で取り除いてしまう。
 - [Free Markdown to HTML Converter](https://markdowntohtml.com/)

[^markdown]: 有志のアドオンを使えば対応できる。ただ、今のところマークダウン対応アドオンは乱立しており、決定版がない。また、将来Ankiのバージョンアップによって故障する可能性もある。
#### (2) HTMLをスプレッドシートに貼り付け
変換できたHTMLをGoogle スプレッドシートに貼り付ける。[[#(1) Web記事のHTMLを整形する|前の手順]]に沿ってHTMLを整形していれば、`<p>`や`<h2><h3><h4>`ごとに行を区切って貼り付けることができる。

次に、貼り付けた文章を章・節・段落ごとに1セルにまとめる。この作業は残念ながら自分でやらないといけない。
貼り付けた結果をそのまま使ってもよい。ただし、文章が細かく分かれすぎることが多いので、Ankiに取り込んだときに「この文章って何の話だったっけ？」と困惑する。

#### (3) 2列目には参照元を記述
Google スプレッドシートの2列目には、参照元の情報（どこから得た情報か）を載せておく。特に以下の情報は必ず残しておこう。後で原文を確認しやすいので便利。

- 名称（Webページのタイトル、書名、作品名）
- 情報源のURL

ただ、参照元の情報を自分で手入力するのは面倒くさい。なので私は、以下のような参考文献リストの生成サービスを使っている。URLを貼り付けるだけで、参照に必要な情報を自動で取得してくれる。あとは生成された文章を2列目に貼り付けるだけでいい。とても便利。

- [APA7 citation generator. Citefast automatically formats citations in APA 7th edition](https://www.citefast.com/?s=APA7#_Book)
- [Free Citation Generator \| APA, MLA, Chicago \| Scribbr](https://www.scribbr.com/citation/generator/)

#### (4) スプレッドシートからエクスポートする
読みたい文章と参照元を載せたら、スプレッドシートをエクスポートする。Google スプレッドシートの場合、メニューの「ファイル」→「ダウンロード」から出力できる。

出力形式はいくつかあるが、「カンマ区切り形式（CSV）[^csv]」「タブ区切り形式（TSV）[^tsv]」のどちらを選ぼう。個人的にはTSVがオススメ。

[^csv]: Comma-Separated Values。表形式のデータをカンマで区切ったテキストファイル。仕事でパソコンを使う人には馴染み深い。なお、CSVファイルはExcelなどの表計算ソフトでも開くことができる。そのせいで、「CSVファイルとXLSXファイルを同じものだと思い込む」「[CSVファイルをExcelで編集・保存して、数値の16ケタ以降を0にしてしまう](https://learn.microsoft.com/ja-jp/office/troubleshoot/excel/last-digits-changed-to-zeros)」という新人あるあるが頻発する。
[^tsv]: Tab-Separated Values。表形式のデータをタブで区切ったテキストファイル。こちらはCSVと比べて影が薄い。タブはスペースと同じような空白文字だが、スペースとは用途が異なり、もっぱら文章のインデント（字下げ）に使われる。

#### (5) Ankiにインポートする
![[ファイルをインポート.png]]

Ankiのトップページから「ファイルをインポート」を選び、インポートするTSVファイルをファイルダイアログから選ぶ。

##### ファイル
![[インポート_ファイル.png]]

| 項目名            | 設定値                    |
| -------------- | ---------------------- |
| フィールドの区切り      | コンマ(CSVの場合)、タブ(TSVの場合) |
| フィールド内でHTMLを使う | ON                     |

##### インポートのオプション
![[インポート_オプション.png]]

| 項目名       | 設定値                                       |
| --------- | ----------------------------------------- |
| ノートタイプ    | （作成した読書ノートタイプ）                            |
| デッキ       | （[[#1. Ankiに読書用のデッキを新しく作る\|新しく作った読書デッキ]]） |
| 既存のノート    | 更新                                        |
| 重複チェックの範囲 | ノートタイプ                                    |
##### フィールドの割り当て
![[インポート_フィールドの割り当て.png]]

ここで、スプレッドシートの1列目と2列目がデッキの表面・裏面に問題なく対応づけできていることを確認する。

## まずはWeb記事から


- まずは読みたいテキストを用意する
	- 読書用のデッキを新しく作成する
		- 通常のデッキとは違う運用をするので区別した方がいいかも
	- テキストをインポートする
		- スプレッドシート（Excel、Google Spread Sheetなど）を用意する
			- 私はGoogle Spread Sheet
		- 最初は文章を章・節または段落ごとに分ける
			- 最初はざっくりとした機械的な分け方でOK
				- それでも長すぎる場合は、分割した章・節・段落からさらにざっくり分ける
		- 一列目
			- テキストを入れる
			- HTMLの場合
				- 不要なタグをクレンジングする
					- 私はマークダウン化→再度HTML化でクレンジングしている
					- MarkdownをHTML化するアドオンを入れてもいいかも
			- PDFの場合
				- テキストを拾うサービス等で文章を取得する
					- PDFから1ページずつ文章を貼り付けでもいいが、時間がかかる
		- 二列目
			- ここは個人の好み
				- 私は情報源などの情報を入れている
				- 面倒であれば空欄でもいい
- Webサイトや電子書籍といった電子媒体がいい
	- 文章のインポートが楽になる
